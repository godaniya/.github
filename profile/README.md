# Godānīya

Godānīya develops independent software for astronomy, astronomical timekeeping, and place-aware experiences.

## Current project

[Astronomical Clocks Wallpaper](https://github.com/godaniya/astronomical-clocks-wallpaper) is in development: an offline Android live wallpaper inspired by astronomical clocks, starting with Prague’s Orloj.

- Read the [project README](https://github.com/godaniya/astronomical-clocks-wallpaper/blob/main/README.md) for its scope and setup.
- See the [contribution guidance](https://github.com/godaniya/astronomical-clocks-wallpaper/blob/main/README.md#contributing) for how to help.
